# Web Interface Design Guidelines

## 1. Visual Hierarchy

Establish a clear hierarchy using:

- Typography
- Spacing
- Contrast
- Alignment
- Content grouping

Prioritize the user's main task.

Avoid competing primary actions.

## 2. Color System

Define semantic colors:

- Primary
- Secondary
- Background
- Surface
- Text
- Muted text
- Border
- Success
- Warning
- Error

Use restrained accent colors.

Ensure sufficient contrast for readable text.

Do not rely on color alone to communicate state.

## 3. Typography

Use a consistent type scale.

Recommended starting values:

- Hero: 36–56px on desktop
- Page title: 28–36px
- Section title: 20–28px
- Body: 14–16px
- Supporting text: 12–14px

Adjust values for content density and device size.

Use comfortable line heights.

For Chinese interfaces, verify text wrapping
and font rendering separately.

## 4. Spacing

Prefer a consistent spacing scale:

4, 8, 12, 16, 24, 32, 48, 64px

Use whitespace to establish relationships
and reduce unnecessary visual noise.

Do not apply identical spacing to every context.

## 5. Cards

Cards should contain:

- A clear primary element
- Supporting information
- Consistent internal spacing
- Appropriate interaction feedback

Use subtle borders or shadows when helpful.

Avoid excessive shadows and nested cards.

## 6. Images

Use relevant, high-quality images.

Maintain consistent aspect ratios.

Prevent layout shifts where possible.

Provide meaningful alternative text.

Do not misrepresent placeholder images
as real product or listing photography.

## 7. Motion

Use motion to communicate state changes.

Prefer subtle transitions:

- Hover feedback
- Focus feedback
- Selection changes
- Modal transitions

Avoid unnecessary continuous animation.

Respect reduced-motion preferences.

## 8. Responsive Design

Mobile:
- Prioritize essential content
- Use clear touch targets
- Avoid horizontal overflow
- Simplify complex navigation

Desktop:
- Use available space intentionally
- Maintain readable content widths
- Avoid excessive stretching

## 9. Accessibility

Use semantic HTML.

Provide keyboard-accessible controls.

Show visible focus indicators.

Associate labels with inputs.

Check color contrast.

Ensure interactive elements have
appropriate accessible names.

## 10. Final Review

Inspect at least:

- One narrow mobile viewport
- One wider desktop viewport

Check:

- Layout overflow
- Text truncation
- Image cropping
- Navigation behavior
- Empty states
- Form interactions
- Visual consistency

Report any checks that could not be performed.
