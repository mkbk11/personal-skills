# Photo Coach｜中文介绍与使用指南

> 把 AI 当作私人摄影导师：出门前帮你选择镜头和拍摄策略，拍完后认真点评作品，再通过练习让下一次拍得更好。

[返回仓库首页](../README.md) · [查看 Skill 执行规则](../photo-coach/SKILL.md)

## 1. 技能定位

`photo-coach` 为摄影爱好者提供**拍前准备、现场参数、照片点评、后期修图和渐进式陪练**。它不仅说照片“好不好看”，还要解释画面的优点、问题为什么出现，以及怎样通过改变站位、光线、构图或相机参数改善。

默认中文回答，解释必要的摄影术语；尤其适合旅行记录、城市扫街、人像、风光、夜景、静物和运动摄影。以拍摄体验和个人审美成长为中心，优先发挥现有器材的潜力。

## 2. 适用场景

- **拍前准备**：去澳门、珠海旅行或拍城市夜景前，决定带哪支镜头、拍什么、怎么设置。
- **单张点评**：上传照片，分析构图、主体、光线、曝光、色彩和叙事效果。
- **多图选片**：筛选旅行相册、挑选作品集照片，决定叙事顺序。
- **后期修图**：规划 Lightroom / Camera Raw 等软件的局部与整体调整步骤。
- **专项训练**：学习光圈、快门、ISO、对焦、景深、决定性瞬间和个人风格。
- **器材与参数问题**：判断镜头适配、使用取舍，以及是否真有必要升级设备。

## 3. 核心能力

| 能力 | 主要工作 | 典型产出 |
| --- | --- | --- |
| 场景与镜头选择 | 根据题材、光线、体力和器材确定策略 | 建议镜头/焦段与取景清单 |
| 相机参数指导 | 平衡光圈、快门、ISO、对焦和防抖 | 起始参数与现场调整方法 |
| 照片点评 | 分析可见画面并找出优先级最高的问题 | 亮点、改进建议、重拍与后期区分 |
| 非破坏性修图 | 组织裁剪、色调、局部蒙版与细节处理 | 按步骤执行的修图方案 |
| 选片与作品集 | 综合题材、故事、技术质量和重复性 | 入选理由、相册排序与主题 |
| 摄影陪练 | 围绕真实问题设置短时练习 | 15–30 分钟任务、复盘与下一步训练 |

## 4. 输入与输出

**建议提供：**

- 照片或相册；若未拍摄，可给出地点、时间和准备拍的题材。
- 希望的风格：真实纪实、自然人像、电影感、黑白、通透风光等。
- 当前实际机身、镜头，以及三脚架、闪光灯等可用附件（不确定也可以先不填）。
- 遇到的问题：虚焦、运动模糊、曝光不准、背景杂乱、后期不自然等。
- 如果可用，可提供 EXIF、RAW/JPEG、修图软件和拍摄意图。

**通常得到：** 可直接执行的镜头与设置建议、照片优点、最优先的 2–3 项改进、重拍和后期方案，以及下一次练习任务。根据请求可以只给简短参数表，也可以详细解释原理。

**关于你的参考器材：**此前讨论过 Nikon Z6II、NIKKOR Z 24–200mm f/4–6.3 VR 和 TTArtisan AF 50mm f/1.8 NEO，但**是否购买尚未确认**。Skill 会以你最新确认的设备为准，避免默认你拥有全部器材。

## 5. 使用步骤

1. **明确需求**：例如“点评这张照片”“教我拍夜景人像”“帮我规划一次澳门扫街”。
2. **提交素材或场景**：上传照片，或告诉 AI 当前光线、主体是否移动、器材和可用时间。
3. **选择反馈方式**：速评、深入点评、参数速查、后期流程、选片或一周练习；拍后可继续提交新作品进行迭代。

在支持个人 Skills 的 ChatGPT 中可用 `@photo-coach` 指定；在其他支持命名 Skill 的 Agent 中按其调用方式使用 `$photo-coach`。

## 6. 使用示例

**示例 1｜上传照片，进行专业点评**

```text
使用 $photo-coach 点评我上传的这张照片。
请分析主体、构图、光线、色彩、背景和画面故事。
先告诉我最成功的一点，再按优先级列出 3 个改进建议。
区分哪些可以通过后期处理，哪些需要下次重拍。
最后给我一个可以立刻实践的拍摄练习。
```

**示例 2｜澳门城市扫街，拍前准备**

```text
使用 $photo-coach 帮我准备一次澳门城市扫街。
参考 Nikon Z6II、24–200mm 和 50mm f/1.8 的候选组合，
以轻松旅行和城市记录为主，推荐镜头、焦段、参数起点、
对焦模式和 5 个具体拍摄任务，并说明弱光时如何调整。
```

**示例 3｜夜景人像参数指导**

```text
使用 $photo-coach 教我拍夜景人像。
场景：晚上、手持、人物有轻微移动，背景有霓虹灯。
解释镜头、光圈、快门、Auto ISO、对焦和白平衡的取舍，
并教我避免人物虚焦、运动模糊和灯牌高光过曝。
```

**示例 4｜Lightroom 后期调色**

```text
使用 $photo-coach 为这张照片制定 Lightroom 修图流程。
希望风格自然、有层次、略带城市电影感，但不要过度饱和。
按裁剪、白平衡、曝光、局部蒙版、色彩和细节的顺序指导，
说明每一步的理由；不要在未看到原图时编造精确滑块值。
```

**示例 5｜旅行选片与摄影成长**

```text
使用 $photo-coach 从这组旅行照片中挑选 6 张做摄影作品集。
说明每张入选或淘汰的理由，给出有故事感的排列顺序。
再总结我的共同问题，安排下一周 3 个短时摄影练习。
```

## 7. 使用建议与边界

- **先定拍摄目标**：人像、街头记录和风光所需的快门/景深不同，不能机械套同一组参数。
- **参数只是起点**：实际光线、主体动作和焦段变化会影响快门、ISO 与对焦；防抖不能冻结运动主体。
- **视觉观察不等于 EXIF**：没有元数据就不推断实际 ISO、快门或镜头；压缩图片也不适合武断评价像素级锐度。
- **区分技术与审美**：纪实、黑白、颗粒或运动模糊可能是有意创作，不应一律当成错误。
- **区分后期与重拍**：RAW 调整有局限，严重失焦或错过的动作通常无法真正挽回。
- **器材推荐注重性价比和可靠性**：只有确认现有设备无法满足需求时，才考虑新增配件和镜头。
